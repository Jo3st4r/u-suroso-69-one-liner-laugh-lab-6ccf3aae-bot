## The line

> The sock walked into my mouth. I have a 400-watt appetite and zero impulse control — dinner is served.

1 sock eaten, 400 watts, 0 impulse control: the vacuum does
not chase the sock — the sock walks into its mouth, so the
blame starts with the victim. Its appetite is a motor rating,
not a metaphor, and the sock is not a mistake or an accident
to apologise for: it is dinner. The turn lands in the last
few words, exactly where the judge looks for it.
